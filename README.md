# End-to-End Automation Project with Playwright & Testscript
[![Playwright Tests](https://github.com/sakthivikramHR/Test_Automation_Engineer/actions/workflows/playwright.yml/badge.svg)](https://github.com/sakthivikramHR/Test_Automation_Engineer/actions/workflows/playwright.yml)

## A fully functional project that helps users to navigate through important concepts of Playwright

This automation project uses important concepts of playwright to handle various kinds of testing and guides you to do the following:

### Basic Tests:

* Testing the Github Login functionality
* Testing the Github Login functionality with Hooks (BeforeAll, AfterAll, BeforeEach, AfterEach): This serves as a precondition and postcondition tests for automation testing
* Testing the Github Login functionality with iFrames

### Advanced Tests: 

* Testing functionalities with a ENV File (Using ENV Files to handle complex data)
* Testing functionalities with Data Driven Testing (DDT): Using multiple inputs to a same test
* Testing functionalities with Data Driven Testing (DDT): Using JSON file to extract multiple inputs
* Testing functionalities with Data Driven Testing (DDT): Using CSV file as multiple inputs
* Testing functionalities with Data Driven Testing (DDT): Using EXCEL file as multiple inputs

### Page Object Model: 

* Testing functionalities with Page Object Model (POM): Decluttering tests by creating POM to free up space and also make the tests less complex by having changeable data in a POM
* Testing functionalities with Page Object Model (POM): Using Fixtures to track the flow of tests

### API Testing: 

* Testing functionalities of API with GET and POST requests: GET request is to check whether data is available or not, POST request is to send new data to the application

### Work in Progress:

* Adding Visual Regression Testing
* Setting up API Mocking to simulate server responses
* Integrate accessibility testing into fixtures to automatically audit WCAG rules during runs
* Configure code quality standards to enforce clean TypeScript formatting
